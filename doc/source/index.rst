MCPL - Monte Carlo Particle Lists
##################################

MCPL files, with extensions ``.mcpl`` and ``.mcpl.gz``, are a binary format for
usage in physics particle simulations. They contain lists of particle state
information, and can be used to interchange or reuse particles between various
Monte Carlo simulation applications.

.. note::

   This is the new Sphinx-based MCPL website, which is still in
   development. The current MCPL website is at https://mctools.github.io/mcpl/.
