************
Installation
************

MCPL is available as Python and Conda packages:

.. code-block:: sh

   pip install mcpl

or:

.. code-block:: sh

   conda install -c conda-forge mcpl

Both provide the C library and header files, the ``mcpltool`` and
``pymcpltool`` commands, and the Python module ``mcpl``. The converters for
other formats (e.g. ``ssw2mcpl`` and ``phits2mcpl``) are in the optional
``mcpl-extra`` package.
