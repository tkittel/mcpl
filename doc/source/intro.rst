************
Introduction
************

MCPL files contain lists of particles, with their types, positions, directions,
kinetic energies, times and weights, and optionally polarisations, custom
per-particle flags and data. They can be written and read by many Monte Carlo
simulation applications, and inspected and modified with the MCPL tools and
APIs (C, C++ and Python).

The format itself is formally described in:

   T. Kittelmann, et al., Monte Carlo Particle Lists: MCPL, Computer Physics
   Communications 218, 17-42 (2017), https://doi.org/10.1016/j.cpc.2017.04.012

All MCPL code is provided under the Apache 2.0 license (see :doc:`license`).
